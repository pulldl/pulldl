# 🛡️ PullDL Security Policy

PullDL takes user privacy, web sandbox security, and data protection with utmost seriousness.

## 🔒 Security Posture
PullDL operates a zero-retention web streaming pipeline:
- No user media or file content is permanently written to server persistent storage.
- Download sessions use transient streaming memory buffers that terminate immediately upon completion.
- Client-side utilities run locally within the user's browser environment using standard Web APIs and WebAssembly.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, privacy concern, or potential exploit in the PullDL web platform:

1. **DO NOT** disclose the issue publicly via GitHub Issues or social media.
2. Please send a confidential report directly to our security team:
   - **Email:** `contact@mahean.com`
   - **Subject:** `[SECURITY] PullDL Vulnerability Report`
3. Include detailed steps to reproduce, affected URLs, and any technical proof of concept.
4. We aim to acknowledge receipt within 24 hours and deploy necessary patches within 72 hours.

Thank you for helping keep the web safe, fast, and private! 🌐
