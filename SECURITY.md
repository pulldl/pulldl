# 🛡️ PullDL Security Policy

PullDL takes user privacy, browser sandbox security, and data protection with utmost seriousness.

## 🔒 Supported Versions
We provide active security patches and updates for the latest released versions:

| Version | Supported |
| :--- | :---: |
| 2.x.x (Turbo) | ✅ Yes |
| 1.x.x | ❌ End of Life |

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, privacy leak, or potential exploit in the PullDL extension or web platform:

1. **DO NOT** disclose the issue publicly via GitHub Issues or social media.
2. Please send a confidential report directly to our security team:
   - **Email:** `contact@mahean.com`
   - **Subject:** `[SECURITY] PullDL Vulnerability Report`
3. Include detailed steps to reproduce, browser version, and affected URLs.
4. We aim to acknowledge receipt within 24 hours and deploy a fix within 72 hours.

Thank you for helping keep the web safe and private! 🌐
